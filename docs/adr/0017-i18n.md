# ADR-0017: i18n: next-intl

- **Trạng thái:** Accepted
- **Ngày:** 2026-11-01
- **Nguồn:** Thiết kế kỹ thuật v1.0 (ADR-17) 

## Context
Quyết định này nằm trong bộ quyết định kiến trúc nền tảng của Allingo (monorepo TypeScript, modular monolith, PostgreSQL 6 schema, AI Gateway).

## Decision
i18n: next-intl (ICU) cho UI; dữ liệu đa ngôn ngữ dạng JSONB `{vi,en,ja,ko,th}`.

## Alternatives considered
Bảng dịch riêng.

## Consequences
Thêm ngôn ngữ = thêm key.
