# ADR-0013: B2B đa tenant: shared schema + cột `org_id` + Row Level Security cho vai trò tổ chức

- **Trạng thái:** Accepted
- **Ngày:** 2026-11-01
- **Nguồn:** Thiết kế kỹ thuật v1.0 (ADR-13) 

## Context
Quyết định này nằm trong bộ quyết định kiến trúc nền tảng của Allingo (monorepo TypeScript, modular monolith, PostgreSQL 6 schema, AI Gateway).

## Decision
B2B đa tenant: shared schema + cột `org_id` + Row Level Security cho vai trò tổ chức.

## Alternatives considered
Schema/DB riêng mỗi tổ chức.

## Consequences
Vận hành đơn giản; RLS bảo vệ dữ liệu giữa tổ chức; API dùng vai trò DB không BYPASSRLS.
